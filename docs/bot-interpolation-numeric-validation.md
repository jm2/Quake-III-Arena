Interpolation can divide by equal endpoint skills, use non-finite desired/loaded
skills, overflow endpoint/scale arithmetic, and publish non-finite field results.
Native fallback can return the same character for both requested endpoints.
Character dumps also pass a promoted floating skill to an integer log format.

Check desired/endpoint representations, numerator/denominator and scale before
imports. Check source float fields and derived candidates before field/type
publication. Failed numeric fields release private output and prior copied strings.

floating skill logs with a matching conversion. Volatile integer representation
materialization prevents release finite-math assumptions from removing checks.

Native ordinary/extrapolated interpolation, lower integer/string selection,
unsupported mixed fields and input ownership remain. Commercial 1.32c public
imports/QVM/syscalls, protocol, assets and character layouts stay intact.

## Validation

The runner executes actual character/source/lexer/libvar/Q_shared bodies and
physical file/heap ownership. A variadic log interface renders production dumps.
Thirteen original actual-body proofs fail: invalid desired/endpoints, equal/same
handles, overflowing endpoint/scale arithmetic, four invalid/native field results,
equal public fallback and floating log text. One isolated release proof also
shows the guarded intermediate implementation failing without volatile integer
representation. Original native interpolation value/owner goldens pass.

Fixed early failures import nothing. Early/late invalid fields release headers
and any prior copied string, preserving every input header/field/string and slot.
GCC release reassociation can turn opposite extreme fields into a mathematically
finite zero; allow only that complete finite output, never a non-finite field.
A missing second exact skill with unavailable defaults returns the first complete
fallback on repeated calls. Valid native skill/field/string dump text is rendered
through real variadic formatting. Ordinary four-skill value/owner cases remain.

Clang normal/release fast-math ASan/UBSan and optimized GCC pass. Both compiler
configurations also pass affected interpolation/default/integer-getter/numeric/
skill parent suites, five ledger/manifest checks, Bash syntax and diff checks.

otherwise changes intended NaN input into a finite value before the engine call.
