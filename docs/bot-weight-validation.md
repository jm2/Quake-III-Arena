# Weight configuration publication and ownership — 2026-09-18

The native weight loader treats a failed top-level source read as EOF and can
publish/cache previously parsed weights after malformed input. Its parse-failure
paths use the public cached-release policy, which retains private allocations
when reload is disabled. The current name is outside the completed-weight count,
a malformed nested separator branch leaks its chain, and configuration/name/
separator imports are dereferenced without checking nullable results.

Keep each current weight in the private cleanup count once its name is staged.
Every parse failure directly releases the unpublished configuration, current
name and complete separator chains, independently of the public cache policy.
Check every configuration/name/ordinary/nested/implicit-default separator import.
Reject recorded source errors before freeing the source or publishing cache slots.
Existing cached owners stay intact. Invalid filename pointers/overlong identities
reject before cache comparisons and imports; native full source path checks remain.

Preserve native valid weight names, return/balance/case/default fields, fuzzy
values, cache reuse, reload ownership and 128-weight warning/truncation behavior.
Commercial 1.32c public imports/QVM/syscalls, native protocol and asset layouts
remain unchanged.
